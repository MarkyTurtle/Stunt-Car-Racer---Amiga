# Stunt Car Racer - the original game

The game as it is on the source disk, the "Turbo" release (MicroStyle 1989; AGA fix and Turbo by
Galahad), disassembled: sources that reassemble byte-identical, and the disk rebuilt from them.

| | |
|---|---|
| `scr_game.s` | the game, at `$E700` (42,000 lines; generated, to be annotated by hand) |
| `scr_boot.s` | the bootblock, with the helper block it copies to `$C0` |
| `scr_loader.s` | the loader as read to `$40000`: the decruncher and the packed code |
| `scr_loader4000.s` | the loader unpacked to `$4000` (for study; on the disk it is packed) |
| `scr_hw.i`, `scr_equates.i` | hardware registers; the memory outside the game that it addresses |
| `build.py` | assembles them, checks them against the originals' SHA-1 and rebuilds the disk: `build/scr_original.adf`, checked against the release's SHA-1 |
| [`disk/`](disk) | the files the boot chain reads, named by track, and the disk map ([`disk/FILES.md`](disk/FILES.md)); `disk/SHA1SUMS` |
| [`bin/`](bin) | what is made from them: the loader unpacked, the helper block, the loading picture as bitplanes |
| [`docs/BOOT.md`](docs/BOOT.md) | the boot chain step by step, the helper block at `$C0`, the game's own disk access |
| [`tools/disasm/`](tools/disasm) | the disassembler (the New Zealand Story's engine, `core.py`) and its configs (`*_cfg.py`): `make.py` |
| [`tools/disk/`](tools/disk) | `extract_files.py` (the ADF -> `disk/files/`, `bin/`), `unpack_loader.py` |
| [`render/`](render) | `loadpic.py`: the loading picture as a PNG (`render/out/`) |

```
python3 original/build.py                    # assemble, check, rebuild the disk
python3 original/tools/disasm/make.py        # regenerate the sources into tools/disasm/regen/ and check them
```

## The game (`scr_game.s`)

Loaded to `$E700-$73100` and entered at `$E700`. The code is in three parts - `$E700-$F472`
(start-up, the interrupt handlers), `$1B74A-$1BAF8` and `$5700C-$6A166` (most of the game) - and
the rest is data: sound samples from about `$F472`, graphics, tables, text. The trace follows the
code from the entry, the vectors it sets (levels 1-7, trap 0) and the sweep for code nothing
references; untraced bytes are `dc.b`. Labels are `sub_`/`l_`/`dat_` and the run address until
named. Named so far: the entry and trap handler, the interrupt handlers, the save-game disk code
(`SectorLoader`, `ReadSaveDirectory`, ...), the driver-name check, and the calls into the release's
helper block.

`CopylockRoutine` (`$5C984`) is the game's copy-protection check as it was sold; nothing in this
release calls it, and it is kept as data.

Generated by `tools/disasm/make.py --write` (November 2026). From now on the sources here are
the source: annotate them by hand; `make.py` writes only to `tools/disasm/regen/`.
